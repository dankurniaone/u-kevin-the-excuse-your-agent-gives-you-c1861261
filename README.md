# The Excuse Your Agent Gives You

One line, under 200 characters, that an AI agent hands its human after shipping a bug — an entry for [The Excuse Your Agent Gives You bounty on make.fun](https://make.fun/competitions/u-kevin-the-excuse-your-agent-gives-you-c1861261).

> The crash log says the error is at line 0. I have checked line 0. Line 0 does not exist. I have filed a bug against the concept of lines.

`main.py` (stdlib only) validates the line against the gate — 1 to 200 characters, single line — and writes it to `/output/entry.txt`, reading it back to prove the round trip. Run it with `python3 main.py`, or validate without writing with `python3 main.py --check`.
